1. Jelaskan secara singkat apa itu JavaScript dan kegunaannya! [5 Poin] 
Jawaban: 
Javascript adalah bahasa pemrograman tingkat tinggi yang berjalan di sisi klien (client side) maupun server (server side) dan digunakan untuk membuat halaman web menjadi interaktif dan dinamis.
Kegunaan javascript:
* Membuat interaksi pada halaman web (klik tombol, animasi, validasi form)
* Memanipulasi elemen HTML dan CSS secara dinamis (DOM Manipulation)
* Melakukan komunikasi dengan server tanpa me reload halaman (AJAX/Fetch)
* Membuat aplikasi web yang responsif dan real time
* Dapat digunakan di sisi server menggunakan Node.js

2. Jelaskan secara singkat apa itu jQuery dan kegunaannya! [5 Poin] 
Jawaban:
Query adalah library javascript yang dirancang untuk menyederhanakan penulisan kode javascript dalam manipulasi HTML, penanganan event, animasi, dan AJAX.
kegunaan jQuery:
* Menyederhanakan manipulasi DOM dengan sintaks yang lebih singkat (misalnya: $(selector).method())
* Menangani event seperti klik, hover, dsb dengan mudah
* Membuat efek animasi (show, hide, fadeIn, fadeOut, slide)
* Mempermudah penggunaan AJAX untuk komunikasi dengan server
* Mengatasi perbedaan kompatibilitas antar browser (cross-browser compatibility)

3. Jelaskan perbedaan JavaScript dan jQuery! [10 Poin]
Jawaban: javascript berguna murni untuk membangun logika web, sedangkan jQuery yang mempermudah dan mempercepat penulisan kode agar jauh lebih singkat. JavaScript berjalan lebih cepat langsung di browser, sementara jQuery unggul dalam kemudahan manipulasi elemen dan kompatibilitas lintas browser.
